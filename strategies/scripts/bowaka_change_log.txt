Bowaka — Strategy Change Log
============================

Purpose
-------
This file is the human-readable timeline of Bowaka strategy / prefilter /
analysis edits. When a trade or daily summary looks anomalous, cross-
reference its session date here to understand what code and config were
active on that day. Entries are oldest first.

All times are local (-0600). Each entry is: ISO timestamp | short SHA
| subject | trading-behavior context.

Files in scope:
  strategies/scripts/bowaka_strategy.py
  strategies/scripts/bowaka_strategy.yaml
  strategies/scripts/bowaka_prefilter.py
  strategies/scripts/bowaka_prefilter.yaml
  strategies/scripts/bowaka_analysis.py
  strategies/scripts/bowaka_strategy_README.md
  tests/strategies/test_bowaka_*.py

To extend: run
  git log --reverse --date=iso --pretty=format:"%ad|%h|%s" --all -i --grep=bowaka
and append any new entries with a one-line behavior summary.

How to extend this log
================================================================

When a new bowaka-touching commit lands:

  git log --reverse --date=iso --pretty=format:"%ad|%h|%s" --all \
    -i --grep=bowaka  <last-log-tip>..HEAD

Append a section dated by the commit's author date with:
  - timestamp + short SHA + subject
  - 1–3 bullets on what changed at the YAML / function level
  - one "Behavior:" line stating how a trade run on that date would
    differ from a trade run the day before.

Keep entries oldest-first. Group commits from the same day under one
date heading. The "Active runtime knobs" table at the bottom should
be regenerated whenever a new operator-tunable flag is added.
