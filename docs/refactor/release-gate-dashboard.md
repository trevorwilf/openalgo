## Per-broker v2 parity status (Phase 6 outcome)

**STATUS: ALL_GREEN.** All 30 India brokers' v2 translators produce
bit-identical output on both `--lane v1` and `--lane v2`, plus with
`API_V2_<BROKER>=1` flipped on for every broker. See
[`docs/refactor/v6-translator-parity-status.md`](v6-translator-parity-status.md).

This sentinel unblocked Phase 9 (v1 sunset machinery), which has now
shipped (logical conditional mount + OPENALGO_V1_SUNSET_DATE
enforcement).

API_V2_<BROKER> flags continue to default to **OFF** per ADR 0005;
ALL_GREEN means the framework is **ready** for any operator to flip
their broker's flag, not that the v2 lane is on by default.
